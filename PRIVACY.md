# Privacy Statement

RuneGrid Tactics is a native local-first Godot game. Core gameplay records are stored by the application under Godot’s `user://` location on the player’s device. These records can include settings, progression, achievements, statistics, mode history, replay metadata, unlocks, and an active encounter snapshot.

The game does not require a player account, online tracking storage, precise location, contacts, advertising identifier, payment data, or cloud database to play the core tactical loop. A player can deliberately export a local record and import a validated record later. An import is checksum-validated before it replaces primary local state, and the application keeps a rolling local backup.

Device storage can be removed by uninstalling the application, resetting a device, clearing app data, or user action. Players should create an export before an operating-system reset or device migration. For a privacy question, contact **supportramsandesh@gmail.com**.
