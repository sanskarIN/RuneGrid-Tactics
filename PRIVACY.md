# Privacy Statement

RuneGrid Tactics stores core gameplay records locally in the browser by default. The record may include settings, progression, achievements, statistics, mode history, replay metadata, unlocks, and an active encounter snapshot. Core tactical gameplay does not require a player account or a remote database.

The app provides explicit export and import controls. An export is generated only when the player selects it; an import is parsed and checksum-validated before it is accepted. The project does not ask the player to provide a name, email address, payment data, precise location, contacts, or advertising identifier to play the core game.

Local browser storage can be deleted by browser settings, device resets, storage eviction, or user action. Exporting a field record is the player’s backup option. The project may include deployment-level aggregate analytics in its host environment; those host controls are managed separately from gameplay data and are not used to gate play.
