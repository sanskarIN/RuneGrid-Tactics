# RuneGrid Tactics — Asset Manifest

## Art Direction

**Runic Field Manual:** contemporary cartography and expedition ephemera translated into a tactical tabletop. The visual system uses charcoal basalt fields, smoked parchment dossiers, subdued moss, restrained rust, and one decisive player-agency color: Routeglass Blue (`#56D6E6`). The board is a shallow 3/4 view with visible movement routes, physical token silhouettes, and information that feels field-authored rather than dashboard-generic.
