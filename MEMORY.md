# RuneGrid Tactics — Implementation Memory

## 2026-08-24: Foundation

- The project uses the WebDev `web-static` React 19 host with a Babylon.js runtime.
- The implementation uses a 2.5D orthographic board, not a native Android bundle. This preserves the Android-first touch layout intent while remaining deployable as a browser game.
- The assigned repository currently contains only its initial MIT license commit. It will be synchronized after the WebDev project reaches a verified release state.
- Generated art URLs are recorded in `ASSETS.md`; they must be referenced directly and must not be copied into the project tree.
- The route’s sole rendered experience will be `GameCanvas`; React provides lifecycle containment only. The HUD and menus are generated by the framework-independent `GameUIController`.
- The visual target uses practical board geometry and no unsupported effects such as volumetric fog, complex shadows, or post-processing.
